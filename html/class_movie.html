Detailed Description

Класс, описывающий фильм.

Класс хранит основную информацию о фильме: название, год выпуска, рейтинг, жанр и продолжительность.

Класс обеспечивает проверку корректности данных и не позволяет установить недопустимые значения для основных характеристик фильма.

Также класс содержит статический счётчик количества существующих объектов.

Warning
Название фильма не может быть пустым.
Рейтинг должен находиться в диапазоне от 0 до 10.
Продолжительность должна быть больше 0.
